Projects

Messaging app

Me and my teammate designed and developed a messaging application that offers users multiple ways to interact with the platform, including signing up, logging in, or accessing it as a guest. The app enables users to save chats for future reference, providing a seamless and personalized communication experience. It supports both single-person and multi-person chats, with additional options for managing group conversations, such as adding, removing participants, or changing the name of the group. By implementing robust authentication, postman testing, and error handling, I ensured the app was secure and user-friendly, meeting the expectations of a modern communication platform. The project taught me my first steps in creating a full-stack application, integrating front-end and back-end, with the help of my teammate we were able to deliver a product that was both visually appealing and functional.

This project was a significant learning experience, as it required me to integrate front-end and back-end technologies while considering scalability and performance. I focused on creating an intuitive user interface alongside an efficient backend to handle data storage and retrieval. The challenges of implementing real-time communication and data synchronization sharpened my problem-solving and debugging skills. Overall, the project gave me practical insights into building scalable, interactive systems that prioritize user engagement and security.

Ai Generated Spotify Playlist

My Spotify Web Playback project was an exciting opportunity to integrate music streaming capabilities directly into a web application. This app allows users to authenticate with their Spotify account, stream music from their browser, and view real-time updates on the currently playing track. With a clean and responsive interface, users can see album art, track names, and artist details, all while controlling playback seamlessly from the browser.

A key part of this project involved setting up OAuth authentication and connecting to the Spotify Web Playback SDK to control music playback. I implemented playback controls including play/pause, skip, and previous track functionality, along with real-time updates on the playback state. BikePed Capstone Project

The BikePed Portal project is a collaborative web application designed to visualize historical weather data for pedestrian and bicycle traffic analysis. Working with a team of five others, we researched and will integrate a public API to retrieve weather data, then implemented functionality to collect and store historical weather conditions for different cities in our database.

My main contribution focused on backend development and data handling. I helped set up the API integration, ensured that weather data could be accurately collected for each ZIP code, and built a trigger system that automatically retrieves and stores all historical weather data when a new city is added. Additionally, I assisted in structuring the database to support scalable data queries and contributed to the frontend graphing features, enabling users to visually explore trends through dynamic, interactive charts. This project strengthened my skills in full-stack development, teamwork, and building data-driven applications from the ground up.
